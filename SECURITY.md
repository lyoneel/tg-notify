# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

Please report security vulnerabilities through the repository's
security features or by contacting the maintainer directly. Do NOT
report security vulnerabilities through public issues.

Sensitive information (bot tokens, private chat IDs) should never be
included in a report or issue.
